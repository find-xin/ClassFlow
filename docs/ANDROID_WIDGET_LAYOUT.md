# Android 周课表小组件布局

当前布局实现位于 `WidgetWeekLayout.kt`（纯计算）与 `WeekTimelineGrid.kt`（原生 Glance / RemoteViews 渲染）。它消费 WidgetDataManager 提供的投影，不修改课程、日程或提醒数据。

## 时间与身份

- 优先使用实例的实际起止时间；课程没有显式时间时才按已配置节次查找时间。
- 所有日期共用单调时间轴。同一时间只对应同一个纵坐标，不按每天事项数量重新分配高度。
- 同日真正重叠的事项使用横向分栏；相接但不重叠的事项可以复用同一栏。
- 每个实例只创建一个 Card。按实例 ID、日期和星期去重，不按标题合并不同事项。
- 滚动列表仅在没有事项跨越的时间点切分；卡片和标题不会因节次或固定四节分组被复制。
- 每张卡片直接使用原始 RGB 颜色，并按亮度选择黑白文字，不再映射到近似调色板。

## 渲染与性能

一个列表项表示一个不切断任何卡片的时间区间。七个日期列使用同一坐标系；每张卡片为单一背景和一个标题控件。重叠集合用稳定排序分栏。超出 Glance 子项数量限制的节点递归分组，分组不引入间距。

时间轴保留短事项的可见空间，真实时间仍作为所有日期共用的锚点。窄列和短事项标题可能省略，可点击查看原生详情。显示密度、宿主刷新、长时间滚动及大规模重叠场景仍需按目标设备验收；单元测试和构建成功不代表真机验收。

## 回归覆盖

`WidgetWeekLayoutTest` 覆盖实例不分段、跨日同时间对齐、重叠分栏、相接不重叠、多重重叠、原始颜色、重复缓存、无效时段与周次、课程节次回退、午夜边界与时间解析。真机验证结果记录在 `PROJECT_HANDOVER.md` 最新条目中。
